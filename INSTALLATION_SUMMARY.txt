🚀 QUICK START (3 COMMANDS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Extract:
   $ tar -xzf phd-redaction-webapp.tar.gz
   $ cd phd-redaction-webapp

2. Configure:
   $ cp .env.example .env
   $ nano .env  # Add your Anthropic API key

3. Deploy:
   $ ./deploy.sh
   # OR
   $ docker-compose up -d

4. Access:
   Open browser: http://localhost
